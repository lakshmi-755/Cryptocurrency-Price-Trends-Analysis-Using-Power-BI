# Cryptocurrency-Price-Trends-Analysis-Using-Power-BI

📊 Cryptocurrency Price Trends Analysis Using Power BI

An interactive Power BI dashboard for analyzing multi-year cryptocurrency price trends, market behavior, and financial performance.

📁 Project Overview

This project presents a dynamic Power BI dashboard designed to visualize and analyze the price trends of major cryptocurrencies.
The dashboard provides clear insights into:

Daily price movements (Open, Close, High, Low)

Market Capitalization

Trading Volume

Year-wise performance (2017–2021)

Comparison of multiple cryptocurrencies

It transforms raw financial data into meaningful, easy-to-understand visual insights using Power BI’s interactivity and data modeling features.

🚀 Features
✔ Interactive Cryptocurrency Selection

Choose from major cryptocurrencies such as:
Bitcoin, Ethereum, Binance Coin, Dogecoin, XRP, Stellar, and NEM

✔ Year-Based Filtering

Analyze trends across 2017, 2018, 2019, 2020, and 2021

✔ KPI Cards

Total Trading Volume

Market Capitalization

✔ Trend Visualizations

Dual line charts for:

High vs Low Price by Date

Open vs Close Price by Date

✔ Modern UI

Dark theme dashboard

Neon highlight accents

Clean, minimal layout for clarity

🛠 Tools & Technologies

Power BI Desktop

Power Query (Data Cleaning & Transformation)

DAX Measures

Excel/CSV Dataset

Data Visualization & Modeling




📈 How the Dashboard Works

Import the dataset into Power BI

Use Power Query to clean and format the data

Create relationships and DAX measures (MarketCap, Volume, etc.)

Design UI with slicers, KPIs, and line charts

Publish or export the dashboard
